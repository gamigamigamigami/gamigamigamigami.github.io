Claude Code 使い方 VSCode編｜拡張機能の導入からログインと許可設定まで

「拡張機能を入れれば使える」と書いてある記事もあれば、「ターミナルでclaudeと入力する」と書いてある記事もあります。初めてだと、最初の画面から違って見えるかもしれません。この記事では、VSCodeの左側に出るチャットパネルを使います。拡張機能を入れ、ログインして、最初の指示を送るところまで。

この記事では、VSCodeの左側に出るチャットパネルを使います。拡張機能を入れ、ログインして、最初の指示を送るところまで。まずはここまでできれば十分です。ターミナルを使う方法は、実際に一度話しかけてから必要になったときに見れば間に合います。

まずはチャットパネルから始める

VSCodeの左端には、ファイルや検索、拡張機能などを開くアイコンが縦に並んでいます。Claude Codeの拡張機能を入れると、ここにClaudeのアイコンが加わります。そのアイコンを押して開く入力欄が、この記事で使うチャットパネルです。

ほかの記事で見かける「ターミナルを開いてclaudeと入力する」という方法は、同じClaude Codeを別の入口から使う手順です。途中でそちらへ移ると画面が合わなくなるので、この記事では後半まで使いません。まずはチャットパネルを表示させます。

インストール前に、ログイン方法だけ確認する

拡張機能を入れた後にはログイン画面が出ます。普段Claudeを使っているアカウントがあり、その契約がClaude Codeに対応しているなら、そのアカウントで進みます。仕事でAnthropic ConsoleやAmazon Bedrockを使うよう指定されている場合だけ、そちらを選びます。指定に心当たりがなければ、最初から三つの違いを覚える必要はありません。

ここで覚えておきたいのは、拡張機能を入れることと、ログインすることは別だという点です。アイコンが表示されても、ログインが終わるまでは会話できません。反対に、アイコンが出ていない段階では、アカウントを見直しても先へ進みません。この順番を分けておくと、止まった場所を見失わずに済みます。

MacとWindowsで操作が分かれるのは、主にターミナルを使う場面です。ここから行う拡張機能の検索、インストール、チャットパネルの表示は、どちらも同じ流れで進められます。

インストール後は、目の前の画面から確認する

インストールを押したら、まず左側にClaudeのアイコンが出たかを見ます。出ていたら押してみて、チャットパネルが開くかを確認します。ログインを見るのはそのあとです。最後に入力欄へ短い指示を送れたら、導入は終わっています。

この順番で見るのは、手前で止まっているのに後ろの設定を変えても直らないからです。たとえばアイコンが無いときにログイン方法を調べても解決しませんし、入力欄まで出ているときに拡張機能を入れ直す必要もありません。

では、最初の目印になるClaudeのアイコンを表示させます。

公式の拡張機能を見分けて入れ、チャットパネルを出すまで

まずはチャットパネルを開けるところまで進めます。

  1. VSCode 左端のアクティビティバーから拡張機能ビューを開き、検索欄に Claude と入力します。
  2. 一覧からClaude Codeを選び、提供元がAnthropicであることを確認します。検索結果の並び順だけでは判断しません。
  3. Install を押します。拡張機能は自動的に有効化されるので、追加の操作は要りません。
  4. 左のアクティビティバーにアイコンが増えたか見ます。増えていれば、そこを押してチャットパネルを開けます。
  5. 増えていなければ、VSCode 本体と拡張機能を再起動します。インストールの失敗ではなく表示の反映漏れなので、これで出てきます。

VSCode のメニューが英語のままでも、Claude Code とは日本語で会話できます。故障ではないので、いまはそのまま進めて構いません。チャットパネルが開いたら、次はログインです。

有料部分の中身

  • 画面ごとの対処表（「画面に出ていること／考えられる原因／次に確認するところ」の3列で7症状ぶん。例：「ログイン画面から先に進まない → 契約か接続方法を確認する」）
  • 現在の許可モードの選び分け（Manual／Plan／Edit automaticallyを、最初の作業でどう使い分けるか）
  • プランモードのレビュー往復（プランがチャットではなく中央のエディター領域に出る理由と、範囲選択でコメントを複数付けて返す手順）
  • 定額プランとAPI利用を混ぜない確認方法、WindowsのPowerShell差、生成コードの誤りを機械的に見つける組み合わせ
  • 3分で終わる接続診断シート（いま見えている画面を埋めると、次に確認するところが分かる記入式テンプレート）

診断シートは、たとえば次の形で使います。

確認したもの記入例この時点で分かること

チャット入力欄ない接続完了前。コード生成の問題ではない
ブラウザ認証許可を押していない次に確認するのはブラウザ

設定を片端から変えるのではなく、いま画面に出ているものから次の一手を一つに絞ります。迷ったときに同じ場所へ戻れるよう、記入して使える形にしてあります。
