Obsidianの使い方｜初心者が最初に決める4設定と、あとでリンクが壊れない置き方

Vaultの作成画面で、保存先を選ぶところで手が止まっていませんか。

あるいは、数十枚メモを書いたあとで気づいた人もいると思います。画像がVault直下に散らかっている。スマホから同じノートが開けない。作り直したほうが早いのではないか。

先に結論を書きます。

Obsidianで最初に決めるべきなのは、プラグインでもテーマでもありません。Vaultの置き場所・リンク形式・添付ファイルの保存先・同期方式、この4つです。

なぜこの4つなのか。Obsidianの保存の仕組みを見ると、説明がつきます。

Obsidianが他のノートアプリと決定的に違う一点：保存先がただのフォルダである

Obsidianはノートをクラウド上のデータベースに保存しません。

書き込む先は、あなたのPCの中の普通のフォルダです。そこに拡張子.mdのテキストファイルとして保存されます。

公式ドキュメントのCreate a vaultでも、Vault（保管庫）は「ローカルのフォルダ」と定義されています。

つまりVaultの正体は、Finderやエクスプローラーで開ける、ただのフォルダ。

そのためObsidianをアンインストールしてもノートは残ります。メモ帳でもVSCodeでも中身が読めます。

ただし裏返しがあります。フォルダを移動したり、Obsidian以外のアプリでファイル名を変えたりすると、その操作がそのままノートに影響します。

アプリが中身を管理してくれるEvernoteやNotionとは、ここで道が分かれます。

Vaultの中には.obsidianというフォルダが自動で作られます。設定・ホットキー・プラグイン・テーマが、全部そこに入ります。

ドット始まりなので、多くのOSでは隠しフォルダ扱いになる。そしてこの一点が後の同期トラブルの主犯になります。

置けるのはMarkdownだけではありません。

公式のAccepted file formatsにある通り、画像（png / jpg / gif / svg / webp）、音声、動画、PDFもVault内に置けばノートから参照できます。

Vaultは資料置き場でもあります。そのため、どこに何を置くかを決めないと確実に散らかります。

初心者がつまずくのは機能ではなく「決める順番」——2週間後に壊れる仕組み

開いた直後のObsidianには、機能らしい機能がほとんど見えません。

そのため多くの入門記事は「プラグインを入れよう」「グラフビューを見よう」と進みます。しかし最初に開くべきは設定 → Files and links（ファイルとリンク）です。

理由は単純です。ここの項目はノートが増えてから変えると、既に書いたリンクの意味が変わるからです。

たとえばリンク形式のNew link formatには、「Shortest path when possible」「Relative path to file」「Absolute path in vault」の3択があります。既定は最短パス。

[[議事録]]と書くだけで済むので快適です。しかし同名のファイルがVault内に2つできた瞬間、どちらを指すかが曖昧になります。

50枚では起きず、300枚になると起きる。

これが「最初は快適だったのに後から壊れる」の中身です。

添付ファイルも同じ構造です。

Default location for new attachmentsの初期値では、Vaultのルートに画像が保存されます。そのためスクリーンショットを貼るたびに、直下が埋まっていきます。

しかも後から専用フォルダへ移すと、リンク形式によっては移動した瞬間に画像が表示されなくなります。

同期も同様。PCだけならiCloudでもDropboxでも問題なく動きます。

ところがスマホアプリを入れた時点で、iOSがアプリに許すファイル保存先の制約と、クラウド側の「実体をダウンロードしていないファイル」の扱いがぶつかります。

ここまでを一言でまとめます。Obsidianの初期設定は好みではなく後戻りコストで決まります。

テーマ・フォント・ホットキーは後から変えても無害です。一方、リンク形式・添付先・Vaultの場所・同期方式は既存ノートに波及する。

この線引きが、この記事の中心です。

この記事で扱う範囲と、有料部分に入っているもの

無料部分で扱ったのは、「Obsidianは何なのか」と「なぜ順番を間違えると壊れるのか」まで。

ここから先は、どの設定画面のどの項目を、どの値にするのかです。選択肢ごとの結果の違いつきで書いています。

有料部分の見出しです。

  • Vaultを作る前に決める3つ：保存場所・名前・同期方式
  • 設定 → Files and links の4項目を、選択肢ごとの結果で決める
  • リンクの書き方と、実際に何が起きるのか
  • スマホアプリ：iOSとAndroidで選べる同期が違う
  • 壊したときに戻す手順（先に確認しておく3つの復旧経路）

「おすすめプラグイン20選」は入れていません。

代わりに、コアプラグインでどこまでできて、どこからがコミュニティプラグインの領域なのかという境界線を書いています。なぜなら、自分で判断できたほうが、他人のおすすめを追い続けるより早く落ち着くからです。

必要な前提は、公式サイトからダウンロード済みであることだけ。

まだVaultを作っていない状態が理想です。ただし既に作った人向けに、作り直さずに直す手順も併記しています。
