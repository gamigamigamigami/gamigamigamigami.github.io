Obsidianの使い方｜初心者が最初に決める4設定と、あとでリンクが壊れない置き方

Obsidianを開いて、最初に聞かれるのがVaultの保存先です。まだノートを一枚も書いていないのに、「どこへ置きますか」と言われても決めにくいと思います。ここを仮の場所で済ませると、しばらくして画像がVault直下に並んだり、スマホから同じノートを開けなかったりします。

ここを仮の場所で済ませると、しばらくして画像がVault直下に並んだり、スマホから同じノートを開けなかったりします。作り直す前に確認したいのは、プラグインやテーマではありません。Vaultの置き場所・リンク形式・添付ファイルの保存先・同期方式の4つです。この4つだけは、後から変えたとき既存ノートへ影響します。

この記事では、最初にVaultの正体を一つだけ確認し、そのあと置き場所→同期→リンク→添付先の順に決めます。プラグインや細かな見た目の話は、その4つが終わるまで脇へ置きます。目標は、設定を覚えることではありません。

最初のノートを書いたあと、置き場所をやり直さずに済む。そこまで一緒に進めます。

Obsidianが他のノートアプリと決定的に違う一点：保存先がただのフォルダである

Obsidianはノートをクラウド上のデータベースに保存しません。PCの中の普通のフォルダへ、拡張子.mdのテキストファイルとして書き込みます。Vault（保管庫）という名前は付いていますが、Finderやエクスプローラーからも開けます。

つまりVaultの正体は、Finderやエクスプローラーで開ける、ただのフォルダ。

そのためObsidianをアンインストールしてもノートは残りますし、メモ帳でもVSCodeでも中身が読めます。ただし裏返しがあって、フォルダを移動したり、Obsidian以外のアプリでファイル名を変えたりすると、その操作がそのままノートに影響します。アプリが中身を管理してくれるEvernoteやNotionとは、ここで道が分かれます。

Vaultの中には.obsidianというフォルダが自動で作られ、設定・ホットキー・プラグイン・テーマが全部そこに入ります。ドット始まりなので多くのOSでは隠しフォルダ扱いになり、この一点が後の同期トラブルの主犯になります。

文章に画像を一枚貼れば、その画像もVaultの中へ保存されます。つまり、最初に置き場所を決める対象はノートだけではありません。ここが分かったので、次はノートや画像が増えた後に変更しにくい設定を、どの順番で決めるかを見ていきます。

困るのは機能より「決める順番」——しばらく使ってから崩れる理由

開いた直後のObsidianには、機能らしい機能がほとんど見えません。そのため多くの入門記事は「プラグインを入れよう」「グラフビューを見よう」と進みますが、最初に開くべきは設定 → Files and links（ファイルとリンク）です。

理由は単純で、ここの項目はノートが増えてから変えると、既に書いたリンクの意味が変わるからです。

たとえばリンク形式のNew link formatには「Shortest path when possible」「Relative path to file」「Absolute path in vault」の3択があります。最短パスなら[[議事録]]と書くだけで済みますが、Vault内に同名ファイルを作ると、どちらを指すのかが曖昧になります。ノートが少ない間は見えなかった問題が、増えた後に表面化するのはこのためです。

添付ファイルも同じ構造です。Default location for new attachmentsの初期値ではVaultのルートに画像が保存されるため、スクリーンショットを貼るたびに直下が埋まっていきます。しかも後から専用フォルダへ移すと、リンク形式によっては移動した瞬間に画像が表示されなくなります。

同期も同様。PCだけならiCloudでもDropboxでも問題なく動きますが、スマホアプリを入れた時点で、iOSがアプリに許すファイル保存先の制約と、クラウド側の「実体をダウンロードしていないファイル」の扱いがぶつかります。

ここまで分かれば、最初に何を決めるかも見えてきます。テーマやフォントは後から気軽に変えられますが、リンク形式、添付先、Vaultの場所、同期方式は、すでに書いたノートにも影響します。だから、この4つだけを先に決めます。

続きで決めること

無料部分で扱ったのは「Obsidianは何なのか」と「なぜ順番を間違えると壊れるのか」まで。ここから先は、どの設定画面のどの項目を、どの値にするのかを、選択肢ごとの結果の違いつきで書いています。

有料部分の見出しです。

  • Vaultを作る前に決める3つ：保存場所・名前・同期方式
  • 設定 → Files and links の4項目を、選択肢ごとの結果で決める
  • リンクの書き方と、実際に何が起きるのか
  • スマホアプリ：iOSとAndroidで選べる同期が違う
  • 壊したときに戻す手順（先に確認しておく3つの復旧経路）

「おすすめプラグイン20選」は入れていません。先に必要なのは数を増やすことではなく、まず標準の機能だけで一枚書いてみることだからです。実際に足りない作業が出てきたところで、初めてコミュニティプラグインを検討します。

必要なのは、公式サイトからObsidianをダウンロードしておくことだけです。すでにVaultを作っていても、最初から作り直す必要はありません。移動して直す手順も載せています。
